# V8 — Windows RTX 3060 Hindi TTS Training & Improvement Plan

You are working on:

https://github.com/vishwajit76/custom-tts

## OBJECTIVE

Build V8 of the Hindi TTS system on a Windows PC with:

- Intel i5-11300H
- NVIDIA RTX 3060 Laptop GPU
- 6 GB VRAM
- 16 GB RAM
- ~1.8 TB storage

The goal is to train/adapt a substantially more natural Hindi TTS model than the current Piper/VITS V7 system while preserving very low latency and enabling multiple concurrent live TTS streams.

The final system must support:

1. High-quality Hindi speech
2. Natural Hindi pronunciation
3. Hindi + Hinglish
4. Natural prosody
5. Multiple voices
6. Male/female voices
7. Young-adult voice profiles
8. Conversational voice
9. Professional voice
10. Emotional/style conditioning where supported
11. Streaming synthesis
12. Concurrent inference
13. GPU acceleration
14. 8 kHz / 16 kHz output pipeline
15. Fast time-to-first-audio
16. Existing V7 compatibility

IMPORTANT:

Do NOT assume Piper is the final architecture.

Do NOT start full Piper retraining.

First benchmark stronger architectures on the RTX 3060, then select the best architecture for adaptation/training.

# PHASE 15 — GPU MEMORY MANAGEMENT

RTX 3060 has only 6 GB VRAM.

Therefore:

- load model once
- never reload per request
- cache reference embeddings
- use FP16 where supported
- use inference_mode
- avoid unnecessary tensor copies
- use CUDA efficiently
- limit concurrent GPU jobs
- implement queue/admission control

Add:

GPU memory watchdog.

If VRAM exceeds safe threshold:

queue the request instead of crashing.
