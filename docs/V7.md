# V7: Hindi voice quality upgrade

Status on 2026-10-02: **code complete on branch `v7`; voices not trained yet.** Training starts when the Kaggle GPU quota resets
(Saturday 2026-10-03 00:00 UTC). Nothing in V7 is "production ready": the blind native-listener test (gate 2 in
[V7-ROADMAP.md](V7-ROADMAP.md)) has not run. The implementation report is [../V7_IMPLEMENTATION_REPORT.md](../V7_IMPLEMENTATION_REPORT.md).

## Architecture

```
request text
  -> persona grammar (opt-in `persona` field; speaker-authored text only)        app/services/persona_grammar.py
  -> normalization (numbers, currency, dates, phones, units, URLs, Hinglish)     app/services/text_normalizer.py, hinglish.py
  -> pronunciation rules, per voice (lexical, names/brands, English, schwa)      app/services/pronunciation/
  -> phrase-aware chunking + punctuation pause plan                               app/services/tts.py
  -> engine: Piper (single- or multi-speaker, speaker = voice x recorded style)  app/services/piper_engine.py
  -> per-voice static gain, boundary fades, soft limiter, soxr resample (8/16k)   app/services/audio_utils.py, tts.py
```

The voice catalog (`voices/catalog.json`, [voices.md](voices.md)) is the single source of voice metadata: gender, age group (with
evidence), style, family, status, recorded styles, and the pronunciation rule groups the voice was trained with. Gender and age are
never inferred from a voice id.

### Pronunciation ([pronunciation.md](pronunciation.md))

Evidence first: 197 probe words run through the espeak-ng `hi` phonemizer the Piper voices use. espeak was wrong on 56 before and is
wrong on 4 after (`bench/results/pronunciation_probe_v7.tsv`). Main fixes: schwa kept before ह and in stem+कर and final clusters, schwa
wrongly dropped (नमस्कार, राजस्थान, ज़िंदगी), यह/वह, number and month words the normalizer itself writes, Latin names and brands. The
layer is **off by default** (`PRONUNCIATION_RULES=off`) so existing voices behave exactly as before; V7 voices pin `all` in the
catalog because their training text was prepared with the same rules. A model trained on rule-corrected labels must be served with
the same rules.

### Persona grammar ([voice-system.md](voice-system.md#persona-grammar-v7))

Rule-based first-person gender agreement (imperfective, progressive, perfective, future, modals, predicate adjectives,
self-descriptions), clause-bounded, never inside quoted or reported speech, never third person, आप/तुम or plural हम. `age_group` is
metadata only: Hindi does not inflect for age.

### Recorded styles instead of DSP emotion

Each V7 voice is a set of speakers in one Piper multi-speaker model: `neutral`, `conversational` and six recorded emotions (`happy`,
`sad`, `angry`, `fearful`, `surprised`, `disgusted`). `condition.style` or `condition.emotion` selects the speaker; voices without
recorded styles keep their old capabilities. DSP pitch/energy stays optional and labelled `:dsp`; it is never reported as emotion.

### Audio ([benchmarks.md](benchmarks.md) section 11; V7 evaluation is section 12)

Measured before changing: loudness spread across the four Piper voices 4.8 LU -> 0.3 LU (static per-voice gain, `VOICE_GAIN_DB`),
punctuation-driven pauses (`PAUSE_PLAN`), 3 ms raised-cosine fades only on audible cut edges (`FADE_MS`). Clipping, seams, DC and
telephony resampling were already clean and were left alone. TTFA p50 34-38 ms warm on the M4 for the custom voice (target < 100 ms).

Gates ([training.md](training.md) section 2c) rejected 3146 of 25713 clips: mostly > 15 s (5.1 h, kept out for training memory),
< 1 s, too little speech, recording-condition outliers, clipping and duplicate text. Accepted audio: median SNR estimate 46.5 dB,
median loudness -21.4 LUFS. Rasa ships no speaker age, so `age_group` stays `unspecified` until a listener screening is recorded.

Rasa style -> V7 speaker: CONV and ALEXA -> `conversational` (3.2 h per voice); WIKI, BOOK, NEWS, INDIC, PROPER NOUN, DIGI, UMANG,
BB -> `neutral` (10-12 h per voice); each Ekman emotion -> its own speaker (0.6-0.95 h each).

Attribution: "Rasa: Building Expressive Speech Synthesis Systems for Indian Languages in Low-resource Settings", Praveen Srinivasa
Varadhan, Ashwin Sankar, Giri Raju, Mitesh M. Khapra, INTERSPEECH 2024; dataset https://huggingface.co/datasets/ai4bharat/Rasa,

| Id | Model | Init | Data | Budget |

Both use seed 1234, experiment ids, sha256-verified checkpoints, the experiment-isolation guard, dataset fingerprint, environment
and config snapshot (`training/kaggle/train_kernel.py`). Launch:
`training/kaggle/push.sh --env VOICE_NAME=hi_v7 --env INIT_MODE=warmstart --resume-from experiments/hi_f-v6-0930T0731Z/checkpoints/final_step402504.ckpt`
(B adds `--slug vishwajit76/custom-tts-hindi-train-high --env VOCODER_WARMSTART=en/en_GB/cori/high/cori-high-500.ckpt --env EXTRA_ARGS=...`).
The high model is about 25x slower than medium per step on the M4 GPU, so it runs on Kaggle only; if it misses the CPU latency target
it becomes a separate quality tier, never the fast path.

## Evaluation

- Automated: `bench/v7_eval.py` on corpus v2 (CER, PER, predicted MOS, speaker similarity, TTFA, RTF, RSS, duration, clipping,
  8/16 kHz), paired deltas with bootstrap CIs. Predicted MOS (UTMOS) is a proxy trained on English and is **not** human MOS.
- Human: [listening-test/v7/README.md](listening-test/v7/README.md), blinded ratings and A/B with native-Hindi listeners; results
  are recorded separately from automated metrics and are the only basis for a "better than V6" claim.

## Licensing and data rights

- Rasa data: CC-BY-4.0, commercial use allowed with attribution (text above).
- **The V7 model weights are not commercially clean yet.** They are warm-started from v6, which was fine-tuned on IndicTTS Hindi
  (recorded as personal use only) from Piper rohan, itself fine-tuned from lessac (Blizzard 2013, research only). The warm-start
  carries that lineage into the weights. A commercial V7 needs a clean initialisation: training from scratch on Rasa (far more
  GPU time) or a base checkpoint whose provenance is cleared. See [licenses.md](licenses.md).
- Software: piper-tts and espeak-ng are GPL-3.0 (network service use is fine; distribution needs GPL compliance).

## Known limits

- No listening test yet; every quality statement above is objective-metric or IPA evidence.
- Pronunciation fixes are verified on espeak IPA of isolated words, not by ear or in connected speech; 4 probe items remain wrong
  (कृपया, बेंगलुरु/Bengaluru, डिलीवरी).
- Persona grammar misses subject ellipsis across conjunctions (मैं आया और सो गया rewrites only the first clause).
- Emotion speakers have 0.6-0.95 h each; their quality is unknown until trained and heard.
- Pause lengths are design choices, not yet validated by listeners.
